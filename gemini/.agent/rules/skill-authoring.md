# Skill Authoring

This document outlines the guidelines and best practices for skill authoring in Antigravity.

## When to use

Use this document when creating new skills for the Antigravity system.

## Inputs I need

- Skill context
- Skill objectives

## Process

1. Define skill objectives.
2. Outline the process step-by-step.

## Outputs

- Completed skill documentation.
- Skills ready for implementation.

## Quality checklist

- Skill aligned with objectives.
- Clarity of content.
