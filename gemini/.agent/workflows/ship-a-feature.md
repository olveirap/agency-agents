# Ship a Feature Workflow

1. **Understand Requirements**: Review the feature request and any existing documentation.
2. **Create Implementation Plan**: Draft a high-level plan for implementing the feature, noting any architectural changes or new dependencies. Ask the user for review.
3. **Write Code**: Implement the feature in code, following existing style and patterns.
4. **Test & Verify**: Run relevant tests, or write new ones to ensure the feature works as expected without breaking existing functionality.
5. **Update Documentation**: Update relevant README, docs, or project tracker items to reflect the new feature.
